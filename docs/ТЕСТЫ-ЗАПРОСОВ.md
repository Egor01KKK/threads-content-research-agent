# Бланк тестов th studio

Как гонять: запусти `make studio`, вбей запрос, дай поработать
примерно две минуты, нажми «Стоп». Запиши в таблицу что вышло.

Что писать в графы:
- **постов** — счётчик «свежих постов» в панели
- **находок** — крупное число в панели
- **годных** — сколько из них ты бы реально написал в личку
- **точность** — годных делить на находок

Берутся только посты моложе суток. Галку «заходить в комментарии»
держи выключенной: она втрое удлиняет прогон и даёт впятеро меньше
находок на пост.

---

## 1. Прямой заказ на работу

Человек прямым текстом ищет исполнителя. Самый ценный тип.

| # | запрос | постов | находок | годных | точность |
|---|--------|-------|---------|--------|----------|
| 1 | кто ищет того, кто сделает сайт | | | | |
| 2 | кому нужна автоматизация или бот | | | | |
| 3 | кто ищет дизайнера на логотип и оформление | | | | |
| 4 | кто ищет монтажёра для видео и рилсов | | | | |
| 5 | кто ищет копирайтера или человека на тексты | | | | |

Замеренная база для сравнения: запрос 1 дал 2-3 находки за прогон,
запрос 2 дал 32 находки. Разброс нормальный, спрос на автоматизацию
в Threads просто гуще, чем на сайты.

## 2. Найм

Ищут не подрядчика, а сотрудника. Заказы длиннее, но их больше.

| # | запрос | постов | находок | годных | точность |
|---|--------|-------|---------|--------|----------|
| 6 | кто набирает людей в команду на удалёнку | | | | |
| 7 | кто ищет ассистента или помощника в проект | | | | |

## 3. Боль без заказа

Человек не ищет исполнителя, он жалуется. Тут продажа сложнее,
зато конкурентов в комментариях нет совсем.

| # | запрос | постов | находок | годных | точность |
|---|--------|-------|---------|--------|----------|
| 8 | кто тонет в рутине и делает всё руками | | | | |
| 9 | у кого не идут заявки и клиенты | | | | |
| 10 | кто не справляется с потоком сообщений и заказов | | | | |

## 4. Совет и цена

Человек выбирает и спрашивает. Заходить надо ответом, а не оффером.

| # | запрос | постов | находок | годных | точность |
|---|--------|-------|---------|--------|----------|
| 11 | кто просит посоветовать сервис или инструмент | | | | |
| 12 | кто спрашивает сколько стоит разработка | | | | |

## 5. Контроль

Эти два нужны, чтобы понять, не врёт ли фильтр.

| # | запрос | ожидание | что вышло |
|---|--------|----------|-----------|
| 13 | кто ищет слона в аренду на выходные | около нуля находок | |
| 14 | повтори запрос 1 ещё раз через час | те же люди или новые | |

Если тринадцатый даст находки, агент тащит что попало и промпт надо
ужесточать. Если четырнадцатый даст ровно тех же людей, значит живых
заявок по теме мало и нужен фоновый режим, а не разовые прогоны.

---

## Куда смотреть в результатах

- **Возраст поста.** Под ником написано «3 ч назад». Чем свежее, тем
  меньше конкурентов успело написать.
- **Число ответов.** Иконка со стрелкой внизу карточки. Ноль ответов
  значит ты первый. Двадцать значит ты двадцать первый.
- **Строка «Ищет ...»** под текстом. Это объяснение агента, почему он
  взял пост. Если объяснения натянутые, запрос сформулирован размыто.
